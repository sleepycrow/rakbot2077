## adminie jak ustawić???

1. `deno install`
2. Skopiuj `.env.example` jako `.env` i ustaw tam `BASE_URL`, `USER_ID` i `PASSWORD`
3. Wykonaj `deno task auth` aby się zalogować i skopiuj z outputu token
4. Wklej token do `.env` pod klucz `TOKEN`
5. Teraz możesz już uruchamiać bota wykonując po prostu `deno task start`
